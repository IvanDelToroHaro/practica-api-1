# Proyecto Spring Boot

Proyecto Maven generado con el arquetipo de prácticas. Incluye Spring Web,
Spring Data JPA y el conector de MySQL.

Configura las variables de entorno `DB_USERNAME` y `DB_PASSWORD` antes de
conectar con la base de datos. El nombre inicial de la base de datos coincide
con el `artifactId` del proyecto.

Para ejecutar la aplicación:

```text
mvn spring-boot:run
```
